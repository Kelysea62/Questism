# Prepared AI Dungeon listing

Status: draft. Suggested title: **Questism — Quest Engine (Beta)**

## Description

Give your AI Dungeon stories a persistent quest journal.

Questism tracks authored quests, NPC offers, player acceptance and objective progress. Build linked questlines with prerequisites, required and optional objectives, alternative solutions, scene conditions and competing routes. Keep several quests active and browse them through saved cards or journal commands.

Choose automatic progression or review proposed changes yourself. Optional quest interludes separate updates from the story, while completion verification checks proposed progress before it is recorded. Questism keeps offers, agreement and actual performance as separate events. Quests are voluntary: required objectives define completion, not an obligation to follow the quest. Rewards remain descriptive.

The download includes the reusable engine, ready-to-paste sample Libraries, editable quest packs and creator guides. The root engine starts without preloaded quests; choose a sample or import your own pack.

This is v0.1.29 beta candidate. Its recorded local gate passed 1,207 checks across 48 suites. The preceding v0.1.28 Gemma run completed the five-stop integration path, with one rejected false offer followed by ordinary dialogue recovery. The new v0.1.29 wording has not been rerun live. Model interpretation can still miss or misread an event; other models and untested branches need separate evaluation.

Install one Library with the included Input, Context and Output panes. Turn Optimized Context OFF and Raw Model Output ON. Start with START_HERE.md in the download.
