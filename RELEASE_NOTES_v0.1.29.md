# Questism v0.1.29 — voluntary quests

Quests are optional, even tracked/auto-assigned. Follow the player's scene; do not redirect it, nag or invent quest pressure. Preserve NPC motives and logical consequences. Required objectives define completion, not obligation.

This rule is now supplied in the generic narrator packet and the bounded automatic-offer fallback. Control Panel help explains the same distinction. Existing compatible control cards refresh the help while preserving their settings and creator Notes. All six configured Libraries use the updated engine.

The opening guidance was condensed to 632 characters combined, within the previous 634-character opening body, so the new rule does not crowd out the existing records/offer capacity. Existing current-objective, answered-inquiry, player-sovereignty and reward instructions remain explicit. Context caps were not raised.

Compatible v0.1.28 saves use the existing migration format. Current local regressions exercise settings/definition retention, pending progress acceptance exactly once, Undo/source-edit rollback, unrelated actions in both report modes, no-input Continue and the automatic-offer fallback. This is guidance and help, not a new quest status or a requirement to abandon work before doing something else.
